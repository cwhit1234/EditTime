# EditTime

Finishes Blizzard's Edit Mode for World of Warcraft Forever.

EditTime doesn't replace Edit Mode, it adds to it. Select a frame in Edit Mode and EditTime's settings appear in
a panel attached to Blizzard's own settings window, styled to match. Every setting is saved per Edit Mode layout.

## Features

- **Match Width and Match Height.** Make your cast bar exactly as wide as your Essential Cooldowns, or your
  vertical micro menu as tall as the minimap. Works with the cast bar, Personal Resource Display, experience and
  reputation bars, swing timer bars, damage meter, chat frame, bags and micro menu, and keeps up as the other
  frame changes size.
- **Visibility.** Always, In Combat, Out of Combat or Hidden for the minimap, quest tracker, experience and
  reputation bars, bags and micro menu.
- **Raid frame growth.** Grow your raid frames from the center, or in any direction, so a centered healing
  layout stays centered as people join and leave.
- **Party and raid frame options.** Hide your own frame, hide the "Party" title, hide DPS role icons, and only
  show power bars for tanks and healers.
- **Keybind text.** Shorten action bar keybinds (Shift + Mouse Button 4 becomes SM4) or hide them.
- **Experience and reputation text.** Show Current / Max, a percentage, or both.
- **More frames you can move.** Target of Target, Focus Target, Toasts and Loot Rolls get Edit Mode selection
  boxes, complete with grid and frame snapping. Toasts and loot rolls can also grow downward.

## Notes

EditTime is built so it never causes "Interface action failed because of an AddOn" errors. It never changes
Blizzard's code or Edit Mode's saved data, and protected frames like the party and raid frames are only changed
out of combat.
